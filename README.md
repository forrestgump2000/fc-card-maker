# FC Card Maker

Make your own football player card in the browser.

- Add card designs from your camera roll (saved on your device)
- Add a player photo, name, rating, position, country and team
- Set PAC, SHO, PAS, DRI, DEF and PHY from 45 to 99, or hide any of them
- Save the finished card as a PNG

Static site with no build step.
